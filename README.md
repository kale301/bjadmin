*   **🤖 AI 智能助手与监控中心**
    *   **AI 大模型**：外部无缝连接高级 AI 平台，轻松搞定智能对话与文档处理。
    *   **AI 智能监控 & 监控大屏**：支持配置普通摄像头（RTSP/HTTP流地址），让老旧监控秒变 AI 智能监控，提供一体化实时 AI 监控报告。
*   **📊 数据与文本处理专家**
    *   **JSON / SQL 格式化**：为程序员和数据分析师量身打造，高效美化、校验与转换 JSON 数据和 SQL 查询语句。
    *   **数据差异性比较**：支持 Excel 与 JSON 数据的智能差异对比，免去肉眼逐行比对的痛苦。
*   **🎨 图像与多媒体处理工具**
    *   **图片去水印**：智能抹除图片水印与背景杂质，一键还原本图。
    *   **图片无损压缩**：在保持高清画质的同时，快速降低图片文件体积。
    *   **图片长图拼接**：支持多张图片横向或纵向合并为单张长图。
*   **🎬 视频与文档工具**
    *   **视频去水印**：支持在线解析与提取无水印短视频。
    *   **PDF / 图片互转**：支持 PDF 文件与常见图片格式之间的双向快速转换。

## 📖 English Introduction

**BJ Admin Practical Office & AI Toolkit** is a lightweight, all-in-one productivity aggregation toolkit designed for office workers, developers, system administrators, and content creators. It eliminates the hassle of switching between multiple web pages, streamlining high-frequency data processing, multimedia editing, and AI assistance into a single client.

### ✨ Key Features

*   **🤖 AI Assistant & Monitoring Center**
    *   **AI Large Model**: Seamlessly connect to advanced AI platforms for intelligent dialogue and document processing.
    *   **AI Smart Surveillance & Dashboard**: Configure standard camera streams (RTSP/HTTP) to instantly turn regular security cameras into AI-powered smart monitors with real-time reporting.
*   **📊 Data & Text Processing Experts**
    *   **JSON / SQL Formatter**: Efficiently beautify, validate, and convert JSON data and SQL queries for developers and analysts.
    *   **Data Diff Comparison**: Intelligently compare differences between Excel and JSON data, saving hours of manual checking.
*   **🎨 Image & Multimedia Tools**
    *   **Image Watermark Removal**: Intelligently erase watermarks and background impurities from images.
    *   **Lossless Image Compression**: Quickly reduce image file size while maintaining high-definition quality.
    *   **Long Image Stitching**: Merge multiple images horizontally or vertically into a single long image.
*   **🎬 Video & Document Utilities**
    *   **Video Watermark Removal**: Parse and extract watermark-free short videos online.
    *   **PDF / Image Converter**: Fast two-way conversion between PDF documents and common image formats.
